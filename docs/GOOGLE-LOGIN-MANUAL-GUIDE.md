# 🔐 Google লগইন ঠিক করা — ম্যানুয়াল গাইড (৩ মিনিট)

> **কেন হচ্ছে:** নতুন ঠিকানা `admissionhub.pages.dev` Google-এর অনুমোদিত-তালিকায় নেই
> → Google বলে "origin_mismatch"। **কোড-বাগ নয়** — শুধু Google-সেটিংস-পেজে ১টা লাইন যোগ।
> **একবারই করলেই হবে** — এরপর pages.dev-এ Google লগইন চিরকাল চলবে।

## সবচেয়ে সহজ পথ (ফোন-থেকেই করা যায় — কম্পিউটার হলে আরও সহজ)

### ধাপ ১ — Google-এ ঢোকো
যে Google অ্যাকাউন্ট দিয়ে অ্যাপটার গুগল-লগইন বানানো ছিল (ছবিতে যা দেখাচ্ছে: `mahmudrashel1034@gmail.com`)
সেটা দিয়েই **accounts.google.com**-এ লগইন থাকো।

### ধাপ ২ — এই লিংকটা খোলো
ফোন/কম্পিউটার ব্রাউজারে এই লিংকটা লেখো/চাপো:

```
console.cloud.google.com/apis/credentials
```

> লিংক খুললে উপরে **"Select a project"** দেখাবে — সেখানে এক-একটা প্রজেক্টে ক্লিক করে
> দেখো, যেটার ভেতরে **`673030739375`** লেখাটা আছে সেটা বাছো।

### ধাপ ৩ — ক্লায়েন্ট খোঁজো
পেজের মাঝে **"OAuth 2.0 Client IDs"**-র তালিকা → সেখানে **`673030739375-...`**
নামের সারিতে ক্লিক করো (Edit ✏️ আইকন)।

### ধাপ ৪ — ঠিকানা যোগ করো
খোলা পেজে নিচে-নামা → **"Authorized JavaScript origins"** বক্স →
**"ADD URI"** চাপো → এইটা হুবহু লেখো (কপি করে পেস্ট করো):

```
https://admissionhub.pages.dev
```

> ⚠️ শেষে স্ল্যাশ `/` দিও না — হুবহু উপরেরটা। স্পেস-ও না।

### ধাপ ৫ — Save
নিচে **SAVE** চাপো। (ব্যস!)

### ধাপ ৬ — পরীক্ষা
২–৫ মিনিট অপেক্ষা → অ্যাপ খুলে **Google দিয়ে লগইন** করো → ✅ হয়ে যাবে।
