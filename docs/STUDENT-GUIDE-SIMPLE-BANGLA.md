## 🏠 ১. অ্যাপ খুললে প্রথমে যা দেখবে (হোম পেজ)

- মাঝখানে বড় কার্ড: **"আজকের MCQ লক্ষ্য"** — আজ কতটা পড়া শেষ হলো, কতটা বাকি।
- নিচে **Streak (টানা পড়ার দিন)**, **Performance (কতটা ঠিক-ভুল)**, **Smart Insight (কী শিখব)**।
- আরও নিচে: **অগ্রগতির গ্রাফ**, **দুর্বল বিষয়ের রাডার**, **Admission Goal**, **৯০ দিনের রোডম্যাপ**, আর **Study Tools (পড়ার টুলস)**।

## 📚 ৩. Question Bank (প্রশ্ন ব্যাংক) — প্রশ্ন দেখার ও খোঁজার ঘর

**পথ:** নিচের **📚 Bank** বাটন (হোম পেজের "Command Center"-এও **Bank** কার্ড আছে)

**ব্যবহার:**
1. Bank খুললে প্রথমে **বিষয়ের (Subject) তালিকা** দেখবে — বাংলা, English, GK, গণিত ইত্যাদি।
2. যেকোনো বিষয়ে ট্যাপ করো → ভেতরে **টপিক (Topic)গুলো** দেখাবে।
3. টপিকে ট্যাপ করো → সেই টপিকের **সব প্রশ্ন** একে একে দেখবে (উত্তরসহ)।
4. **প্রশ্ন খুঁজতে:** Bank-এর ভেতরে 🔍 Search আছে — শব্দ লিখে খুঁজতে পারবে।
5. ⚙️ নিজের প্রশ্ন যোগ/আমদানি করতে পারবে (Bank → যোগ করুন) — যা তোমার নিজের ফোনের ডেটাবেসে জমা হবে।

> 💡 Bank মানে "পড়ার জন্য প্রশ্ন দেখার জায়গা" — পরীক্ষা দিতে চাইলে যাও **📝 Exam** ট্যাবে।

---

## 📝 ৪. Mock Test (মক টেস্ট — আসল পরীক্ষার মতো)

**পথ:** নিচের **📝 Exam** বাটন → **Exam Center** → 🟢 **"Mock Test"** কার্ডে ট্যাপ → **"Configure Selected Mode →"** বাটনে ট্যাপ

**এরপর ৩টা ধাপ (উইজার্ড):**
- **ধাপ ১ — বিষয় বাছাই:** সব বিষয় / নির্দিষ্ট বিষয় বা টপিক বাছাই (বা "Custom") → Next
- **ধাপ ২ — নিয়ম:** কতটি প্রশ্ন (১০/২০/৩০…), কত মিনিট, নেগেটিভ মার্ক আছে কিনা → Next
- **ধাপ ৩ — ফাইনাল চেক:** সব ঠিক আছে দেখে → **পরীক্ষা শুরু**

**পরীক্ষা চলার সময়:** প্রশ্নের উত্তর দাও → শেষে **Submit** → সঙ্গে সঙ্গে **ফলাফল** (স্কোর, ঠিক-ভুল, সময়) + প্রতিটি প্রশ্নের রিভিউ।

> ⚡ শর্টকাট: হোম → Command Center → **📝 Mock** — সরাসরি কনফিগার-পেজে চলে যাবে।

---

## ⚡ ৫. Flash Test (ফ্ল্যাশ টেস্ট — দ্রুত অনুশীলন, সঙ্গে সঙ্গে উত্তর জানা যায়)

**পথ:** **📝 Exam** → Exam Center → ⚡ **"Flash Test"** কার্ড → **"Configure Selected Mode →"** → ৩ ধাপ → শুরু

**বিশেষত্ব:** প্রতিটি প্রশ্নের উত্তর দেওয়ার **সঙ্গে সাথেই** সঠিক/ভুল দেখাবে (মক টেস্টে শেষে দেখা যায়)। নতুন শেখা বা দ্রুত প্র্যাকটিসের জন্য সেরা।

> ⚡ শর্টকাট: হোম → Command Center → **⚡ Quick Practice** (স্মার্ট-অনুশীলন) — দুর্বল টপিক থেকে প্রশ্ন তুলে দেয়।

---

## ❌ ৬. Mistake Bank (ভুলের খাতা) + Mistake Test

**ভুলের খাতা দেখা:** হোম → **Command Center** (See more →) → **❌ Mistakes**
- এখানে তোমার **সব ভুল উত্তর** জমা হয়, টপিক অনুযায়ী সাজানো।
- প্রতিটি ভুলের পাশে বাটন: **✅ "শিখে গেছি"** (খাতা থেকে মুছে যাবে) বা **↩️ "আবার শিখি"**।
- উপরে ফিল্টার: **Needs Review (আবার দেখতে হবে)** / **Mastered (শিখে ফেলেছি)**।

**ভুল থেকে পরীক্ষা:** **📝 Exam** → Exam Center → ❌ **"Mistake Test"** কার্ড → Configure → শুরু — **শুধু তোমার ভুলগুলো থেকে** প্রশ্ন আসবে। 👌 এটাই সবচেয়ে স্মার্ট পড়া!

## 🕘 ৭. Exam History (পরীক্ষার ইতিহাস)

**পথ:** নিচের **🕘 History** বাটন

- সব পরীক্ষার তালিকা: কোনটা Mock/Flash, কবে, স্কোর কত।
- যেকোনো একটিতে **ট্যাপ করলে** বিস্তারিত: কত ঠিক, কত ভুল, কোন প্রশ্নে ভুল করেছ।
- (পুরনো রেকর্ড মুছতে: Profile → Settings → Data management → Clear Exam History)

## 📊 ৮. Progress (অগ্রগতি) ও ৯০ দিনের রুটিন

**অগ্রগতি:** হোম → **Command Center** → **📊 Progress**
- মোট পরীক্ষা, সঠিকতার হার, সেরা স্কোর, সাপ্তাহিক/মাসিক সময়, গ্রাফ — সব এক জায়গায়।

**Admission Goal ও ৯০ দিনের রুটিন:** হোম-এ **Admission Goal** কার্ড (বিশ্ববিদ্যালয়/ইউনিট/পরীক্ষার তারিখ) + **90-Day Roadmap** চেকলিস্ট; অথবা Command Center → **🎯 Goals**।
- টার্গেট বিশ্ববিদ্যালয় ও তারিখ দিলে দিন-গণনা দেখাবে; রুটিনের কাজ শেষে ✔ টিক দাও।

## 📖 ৯. Vocabulary (ভোকাবুলারি) — শব্দ শেখার ঝুড়ি

**পথ (২টা):**
1. হোম → **Study Tools** অংশে → **📖 Vocabulary** বোতাম
2. হোম → **Command Center** → **"See more →"** → **🔁 Revision** বা **📖 Vocab**

**ভেতরে যা পাবে:**
- যেকোনো শব্দে **🔊 বোতামে ট্যাপ** করলে **ইংরেজি উচ্চারণ শুনতে পাবে** — প্রথমবার ইন্টারনেটে অডিও নামবে, **পরেরবার থেকে অফলাইনেও চলবে** (একবারেই সেভ হয়ে যায়!)।
- প্রতিটি শব্দে: **Synonyms (সমার্থক)**, **Antonyms (বিপরীত)**, **বাংলা অর্থ**।
- Category (A, B…) অনুযায়ী সাজানো; ⚙️ Category settings-এ "Voice cache" দেখা যায়।

## 💡 ছোট্ট টিপস

- **প্রতিদিন ১টা করা ভালো:** Morning → Flash Test (গরম হওয়া) → দুর্বল টপিক → Mock Test (আসল পরীক্ষা) → ভুলগুলো Mistake Bank-এ দেখো।
- **কোনো ডেটা হারাবে না:** সব পড়া, পরীক্ষা, ভুল, ভোকাব — তোমার ফোনেই নিরাপদে থাকে; ইন্টারনেট না থাকলেও আগের সব কাজ চলবে।
- **দুর্বল বিষয় আসলেই দুর্বল?** Home-এর Weakness Radar আর Smart Insight-এ শুধু তোমার **আসল পরীক্ষার** ফল দেখায় — সেখান থেকেই পরের পড়ার পরামর্শ পাবে।
